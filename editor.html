Can't connect?
  • Use Chrome or Edge on a computer. Safari and phones don't support Web MIDI.
  • When the browser asks to control MIDI devices, choose Allow. If you blocked it, use the icon in the address bar to allow it again.
  • Close any app that has DCLK open (a DAW, MIDI monitor). On Windows only one program can use a MIDI port at a time.
  • The editor needs firmware 1.3 or later. Update with the firmware flasher.
  • Previews embedded in another site may be blocked from MIDI devices. Open this page directly in its own tab.
